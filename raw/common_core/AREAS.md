# Common Core areas, 2026-27 intake

Area codes used by the curriculum page, for Phase 2 to map onto catalog
courses. Credits and rules come from `curriculum.html` and the two PDFs in
this folder — not from this list, which is only a checklist of names.

| Code | Area |
|---|---|
| `HAIC` | Human-AI Co-Creation and Data Literacy (Foundations) |
| `HMW` | Habits, Mindsets, and Wellness (Foundations) |
| `E-Comm` | English Communication (Foundations) |
| `C-Comm` | Chinese Communication (Foundations) |
| `A` | Arts (Broadening) |
| `H` | Humanities (Broadening) |
| `S` | Science (Broadening) |
| `T` | Technology (Broadening) |
| `SA` | Social Analysis (Broadening) |
| `SUS` | Sustainability (Broadening) |
| `UxOP` | Experiencing: UROP / UTOP / UPOP / UCOP (0 credits) |

## Structure

- **Foundations — 18 credits.** HAIC, HMW, E-Comm, C-Comm. All compulsory;
  recommended in year 1. HAIC is new for the 2026-27 intake.
- **Broadening — 12 credits.** 12 credits from four *different* non-home
  areas. A program's home area(s) depend on its school, so what counts
  differs per program — see `Program-specific_Credit_Requirements_2026.pdf`.
- **Experiencing — 0 credits.** Any one UxOP: UROP, UTOP, UPOP or UCOP.
